Settings

Operational configuration. Credentials and secrets stay in the environment — never in the browser.

Environment-level secrets

Login passwords, CYBERAUDIT_SECRET, ingest tokens, and API keys are set via environment variables. The UI does not accept or display them so they cannot leak through screenshots or XSS.

  • CYBERAUDIT_USER / CYBERAUDIT_PASSWORD (admin)
  • CYBERAUDIT_ANALYST_USER / PASSWORD
  • CYBERAUDIT_VIEWER_USER / PASSWORD (client role)
  • CYBERAUDIT_SECRET (required in production)
